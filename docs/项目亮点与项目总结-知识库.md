# Iris Agent 项目亮点与项目总结

## 项目亮点——知识库方向

### 1. 搭建完整的企业级 RAG 知识库链路

实现资料导入、内容解析、智能分块、向量化、混合召回、结果重排、上下文组装和答案引用的全流程闭环，使知识库不仅“能检索”，还具备可评测、可调试、可追溯的工程能力。

### 2. 支持多格式文档统一解析与管理

支持 PDF、Word、Excel、PPT、Markdown、TXT、HTML/MHTML 及常见图片格式导入，并提供知识集合、主题分类、批量移动、删除、重新索引和失败重试等管理能力。

### 3. 优化文档切分，解决长文本上下文丢失

采用语义切分与父子分块策略：子块负责精准召回，父块负责补充完整上下文；同时保护标题、问题和答案边界，减少长答案被拆散、标题与正文分离等问题。

### 4. 构建多路混合检索架构

综合 BM25 关键词检索、向量检索和知识图谱召回，通过 RRF 完成多路结果融合，再结合重排模型与 MMR 去重，提高复杂问题、专业术语和模糊表达下的检索准确率。

### 5. 针对真实用户问法设计查询优化机制

针对用户口语化、简称化和上下文指代式提问，在保留原始问题的基础上补充领域标准词。扩展查询用于提升召回，原始问题继续用于重排，在提高命中率的同时降低语义漂移风险。

### 6. 建立数据驱动的知识库评测体系

构建原始问题、口语化问题和困难问法三层评测集，引入 Hit@K、Recall@K、MRR、NDCG 等指标，并支持评测历史、Bad Case 记录与失败案例回放。

优化后取得以下效果：

- 原始测试集 Hit@1 从 **70%** 提升至 **88.7%**；
- 原始测试集 Hit@3 从 **82.5%** 提升至 **98.8%**；
- 困难问法测试达到 **100% Top 1**。

### 7. 实现知识引用与结果可追溯

回答内容支持 `[1][2]` 形式的知识引用，用户可以展开来源、查看匹配分数并定位到原始文档切片，降低大模型幻觉，提高回答的可信度和可验证性。

### 8. 提供可视化知识管理与检索调试能力

实现知识图谱、文档思维导图、实体关系编辑、切片编辑、检索链路调试和图谱质量检查，使知识内容、召回结果及问题定位过程更加直观。

### 9. 兼顾知识安全与本地化部署

支持使用本地 `bge-m3` 完成向量化，结合本地知识图谱抽取和本地重排能力，使核心知识数据无需离开本地环境；模型密钥只通过环境变量管理，提升数据安全性。

## 项目总结

Iris Agent 知识库是一个面向专业资料管理与智能问答场景构建的本地 RAG 系统。项目围绕“知识如何准确入库、如何高质量召回、如何验证答案来源”三个核心问题，完成了多格式文档解析、语义切分、父子分块、混合检索、融合排序、知识图谱、结果重排和引用溯源等能力。

在优化过程中，针对文档切分过碎、长答案上下文缺失、本地模型调用不稳定、用户问法与资料术语不一致以及评测标签不准确等实际问题，分别从数据处理、召回、排序和评测四个层面进行改进。最终显著提升了口语化及复杂问题的检索命中率，并形成了一套可评测、可调试、可回归、可持续优化的知识库工程体系。

该项目的核心价值不只是实现知识问答，而是建立了从资料治理、检索优化到效果评估的完整闭环，为企业内部文档检索、技术资料管理和私有知识助手等场景提供了可落地的解决方案。
