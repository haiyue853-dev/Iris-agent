# Iris AI Elements 聊天界面组件化重构设计

## 目标

以用户提供的 AI Elements chatbot 示例代码为结构和交互基准，重构 Iris 的聊天展示层。保留现有后端、会话、附件、工具审批和流式事件能力，使页面在视觉层级、消息排版、折叠组件、工具窗口和输入区域上接近示例，同时保持现有业务功能稳定。

## 已确认范围

- 重构聊天主区域、消息展示和输入区域。
- 保留已确认的紧凑侧边栏方向。
- 使用现有 `assistant-ui` 运行时承载真实数据，不直接迁移到示例的模拟消息状态。
- 显示模型选择、联网搜索和语音输入的预览控件，但暂不向后端发送对应参数。
- 不修改后端消息存储格式或工具审批协议。

## 架构

`irisRuntime` 继续把 Iris NDJSON 流转换为 `assistant-ui` 消息部件。展示层按 AI Elements 的职责边界拆分：

- `Conversation`：消息滚动区域、底部留白和回到底部按钮。
- `Message`：用户气泡、助手正文、消息操作和消息分支。
- `Reasoning`：推理状态、持续时间文案和折叠内容。
- `Sources`：来源计数触发器和折叠列表。
- `ToolGroup`：同轮普通工具的聚合状态和详情。
- `PromptInput`：附件、输入区域、底部工具栏和发送状态。
- `Suggestions`：空白会话或输入区上方的快捷建议。

组件只消费运行时状态，不自行保存第二份消息列表。这样流式更新不会重建或覆盖输入框状态。

## 界面与交互

### 消息区

- 用户消息为右侧紧凑圆角气泡。
- 助手正文直接位于内容栏，不使用包裹整条回复的大卡片。
- 流式生成时在正文末尾显示闪烁光标，结束或失败后移除。
- 复制、导出和重新生成操作保持低视觉权重，仅在对应消息附近出现。
- 消息宽度、间距和排版遵循已确认的 Demo。

### 推理与来源

- 推理运行时显示“正在思考”，完成后显示“思考过程”；若运行时可提供持续时间，则显示“思考了 N 秒”。
- 推理内容默认折叠，使用可访问的按钮与受控区域。
- 同一助手消息的来源聚合为“共 N 个来源”，默认折叠。
- 展开来源后显示安全的 HTTP/HTTPS 链接；本地路径和不安全协议不渲染为外链。

### 工具窗口

- 同一助手回复中的普通工具调用聚合成一个窗口。
- 摘要按状态显示“正在执行 N 个工具”“已执行 N 个工具”或“N 个工具执行失败”。
- 聚合窗口默认折叠；展开后，每个工具仍可单独展开参数和结果。
- 运行、完成和失败状态使用图标与文字共同表达。
- `tool_approval_requested` 不进入普通工具组，继续作为独立审批卡展示确认与取消操作。

### 输入区域

- 输入区采用 AI Elements 示例的 Header、Body、Footer 三段结构。
- 附件预览位于 Header；文本输入位于 Body；附件、语音、联网、模型和发送按钮位于 Footer。
- 发送和停止按钮根据运行状态切换。
- 保留中文输入法组合事件保护；流式消息更新不能改变当前草稿。
- 模型选择、联网搜索和语音输入控件作为预览显示，交互时提示“暂未开放”，不改变实际请求参数。
- 建议词点击后只填入输入框，由用户确认发送，避免误提交。

### 响应式

- 桌面端保留紧凑侧边栏和居中的聊天内容列。
- 窄屏隐藏侧边栏与建议词，将聊天区和输入区扩展到可用宽度。
- 输入框底部工具可自动收缩；模型名称可隐藏，但核心发送与附件按钮必须保留。

## 数据流

1. 用户通过 `PromptInput` 提交文本和附件。
2. `assistant-ui` 把请求交给现有 Iris adapter。
3. `irisRuntime` 消费流式事件并更新当前助手消息的文本、推理、来源和工具部件。
4. 普通工具在当前助手消息内聚合；审批事件保持独立。
5. 展示组件根据部件状态渲染流式光标、折叠摘要和错误信息。
6. 回复结束后保留最终消息，输入组件继续维护自己的草稿和输入法状态。

## 错误处理

- 网络或流式错误显示在当前助手消息底部，不清除用户草稿。
- 工具失败保留名称、参数和可安全显示的结果或错误信息。
- 单个来源无效时忽略该来源，不影响正文渲染。
- 未开放控件仅显示提示，不触发网络请求。
- 附件上传错误继续使用现有附件错误状态和移除能力。

## 测试与验收

- 输入框：中文、英文、数字和 IME 组合输入在流式更新期间保持稳定。
- 流式消息：运行时显示光标，完成后移除。
- 推理：默认折叠，可展开和收起。
- 来源：显示正确计数，只渲染安全链接。
- 工具：同轮普通工具只出现一个聚合摘要；审批卡保持独立。
- 输入工具栏：预览控件可见并提示暂未开放，不修改请求。
- 响应式：桌面与移动布局无溢出，核心操作可用。
- 回归：运行全部 Vitest、TypeScript 生产构建和 Lint。
- 浏览器验收：刷新后持续输入中文与数字，模拟流式状态并检查控制台错误。

## 非目标

- 本次不实现真实模型切换。
- 本次不实现语音转写。
- 本次不新增联网搜索请求参数或后端协议。
- 本次不替换 Iris 后端或持久化模型。
