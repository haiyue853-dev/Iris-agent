# MCP 运行时工具刷新设计

## 目标

MCP 服务启停、白名单更新、创建或删除后，后续主对话立即看到当前允许的 MCP 工具，无需重启后端。

## 方案

`ToolRegistry` 增加按名称前缀移除工具的能力。`McpToolRefresher` 持有注册表和 `McpCenterService`：先发现并构建新的 MCP 工具到临时注册表；只有发现成功后，才清除当前注册表内 `mcp__` 前缀工具并复制新工具。内置工具永不被修改。

MCP 管理路由在配置写入成功后调用刷新器。刷新失败时，配置写入保持成功，但保留此前已注册的 MCP 工具，并返回稳定的刷新错误；调用方可重新检测或修改配置。

## 范围

- 刷新仅影响后续模型请求。
- 已进入工具批准流程的调用使用其已保存的 `ToolCall`，不被刷新中断。
- 不在本次加入后台监听、服务常驻进程或环境变量编辑。

## 验证

- 启用并白名单一个 MCP 工具后，注册表出现该工具。
- 禁用或删除后，注册表不再包含该工具，内置工具仍存在。
- 发现失败时，旧 MCP 工具仍保留。
