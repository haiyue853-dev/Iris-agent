# MCP 管理页白名单配置设计

## 目标

让用户无需手填工具名即可配置 MCP 白名单，使已经接入主对话的 MCP 运行时真正获得可用工具。

## 交互

服务先以空白名单保存；启用后，用户点击“发现工具”。后端返回工具名称、描述和只读标记，页面在该服务卡片内显示复选列表。勾选项点击“保存白名单”后写回服务配置；未勾选工具不会注册到主对话。

已保存的白名单在重新打开页面时显示为已勾选。发现或保存失败显示现有错误条，且不清空已选项。服务停用时禁用发现与保存操作。

## 接口与数据

`McpCenterService` 增加替换白名单的操作；`PUT /api/mcp/servers/{id}/allowed-tools` 接受工具名数组并返回服务配置。工具发现响应保留 `name`、`description` 与 `annotations`。

前端 `api/mcp.ts` 增加 `setMcpAllowedTools`，`McpPage` 以服务 ID 保存发现结果和待保存勾选项。

## 视觉

继续使用 `skills-page`、`skill-card`、`skill-card-toggle/open/action` 和现有主题变量。工具列表为卡片内紧凑的复选行，状态使用已有边框、灰色辅助文本和无障碍焦点样式；不增加新主题色或独立页面布局。

## 测试
