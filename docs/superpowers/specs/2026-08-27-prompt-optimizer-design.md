# 提示词优化专家设计

## 目标

在聊天输入框中提供一个图标按钮，将用户当前草稿优化为更清晰、可直接执行的日常工作提示词，并直接替换输入框内容，不自动发送。

## 交互

1. 用户在输入框输入草稿后，点击魔杖图标“优化提示词”。
2. 空白草稿不发请求，按钮保持可用但不执行操作。
3. 请求进行时按钮禁用并显示加载状态；成功后以优化稿直接覆盖输入框文本。
4. 优化失败时保留原文，并显示已有的轻量错误反馈。

## 优化策略

新增内置 Skill“提示词优化专家”。它要求模型保留用户真实意图和语言，补足目标、背景、约束和期望输出，并删去冗余表达。默认面向会议、沟通、汇报、分析、计划、整理等日常工作；不将任务重写为开发任务，也不添加工具调用、代码、文件操作或未提出的执行步骤。只有用户原文明确提出开发工作时，才保留其开发语境。

## 架构

后端增加一个一次性优化接口：加载该内置 Skill，构造不含会话历史的系统提示和用户草稿，调用当前 Provider 后返回纯文本优化稿。该请求不创建会话、不写入聊天记录，也不调用工具。

前端在 Composer 工具区加入一个带 Tooltip 的魔杖图标按钮。按钮调用优化接口并通过 `useComposerRuntime().setText()` 回填内容。它与发送按钮分离，用户仍可自行检查、修改和发送优化结果。

## 验收与测试

- 内置 Skill 能被 SkillCatalog 读取，并声明日常工作提效边界。
- 优化接口将草稿和 Skill 指令交给 Provider，返回清理后的文本；空白输入被拒绝。
- 前端点击图标会将接口返回内容替换进输入框，不提交消息。
- 只运行新增或相邻的后端、前端定向测试及前端构建。
