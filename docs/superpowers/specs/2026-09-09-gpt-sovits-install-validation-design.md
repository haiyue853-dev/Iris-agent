# GPT-SoVITS Windows 安装与验证设计

## 目标

在本机 `D:\AI\GPT-SoVITS` 独立安装 GPT-SoVITS，并验证 WebUI 推理与 `api_v2.py` 的 `/tts` 接口都能生成可播放的 WAV 文件。当前阶段不修改 Iris Agent；语音接入在安装验收通过后单独设计和实施。

## 已知环境

- Windows，NVIDIA GeForce RTX 4060 Laptop GPU，8 GB 显存。
- D 盘约有 156 GB 可用空间。
- 系统 Python 为 3.14，未安装 Conda。
- Iris Agent 工作区已有未提交修改，安装过程不得改动或覆盖这些文件。

## 方案

采用官方 Windows 整合包并安装至 `D:\AI\GPT-SoVITS`。整合包自带隔离运行环境，避免 GPT-SoVITS 的 Python、PyTorch 和 CUDA 依赖污染 Iris Agent 环境。下载只使用 GPT-SoVITS 官方仓库指向的发布源。

## 执行流程

1. 检查目标目录，确保不会覆盖既有安装；若目录非空则停止并报告。
2. 下载官方 Windows 整合包，校验下载文件可正常读取并完成解压。
3. 启动 `go-webui.bat`，确认本地 WebUI 能访问且 GPU 被正确识别。
4. 使用已授权的 GPT/SoVITS 权重、参考音频及其准确文本进行推理；若用户模型尚未提供，先使用安装包可用的基础推理能力验证运行环境，再等待模型路径。
5. 使用同一套推理配置启动 `api_v2.py`，仅监听 `127.0.0.1:9880`。
6. 向 `/tts` 发送本地测试请求，将返回内容保存为 WAV，并检查 HTTP 状态、媒体类型、文件大小和 WAV 文件头。
7. 记录启动命令、模型放置位置、常见故障处理和停止服务方法，形成中文使用教程。

## 安全与边界

- 服务默认仅监听本机回环地址，不暴露到局域网或公网。
- 不提交模型、参考音频、生成音频或第三方整合包到 Iris Agent 仓库。
- 不修改系统 Python，不向 Iris 的虚拟环境安装 GPT-SoVITS 依赖。
- 不删除或覆盖目标目录中的既有内容。
- 声音模型仅用于用户已获授权的用途。

## 验收标准

- WebUI 能启动并完成一次推理。
- `http://127.0.0.1:9880/tts` 能完成一次 POST 推理并返回音频。
- 测试 WAV 可在本机播放，且不是空文件。
- 教程包含日常启动、加载模型、API 启动、测试、停止与常见错误处理。

## 非目标

- 本阶段不训练或微调新模型。
- 本阶段不修改 Iris Agent 的后端、前端或消息协议。
- 不配置公网访问、身份认证或多用户服务。
