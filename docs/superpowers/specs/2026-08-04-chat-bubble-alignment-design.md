# 聊天气泡对齐设计

## 目标

让聊天消息与底部输入框使用同一条居中的内容轨道，避免助手气泡贴近页面最左侧、用户气泡贴近页面最右侧。

## 布局规则

- 消息轨道和输入框的最大宽度统一为 `680px`，并在聊天主区域内水平居中。
- 助手消息贴齐内容轨道左边缘。
- 用户消息贴齐内容轨道右边缘。
- 用户气泡最大宽度为内容轨道的 `80%`，长文本自动换行。
- 助手气泡可占满内容轨道，确保 Markdown、代码块和表格有足够空间。
- 消息操作按钮跟随对应气泡边缘，不改变现有交互。

## 响应式行为

窄屏下内容轨道自动收缩到可用宽度，消息区域与输入区域保持相同水平内边距；用户气泡仍不超过轨道宽度的 `80%`。

## 实现范围

只修改 `web-react/src/App.css` 中消息布局样式，不调整 React 组件、颜色、字体、圆角或后端逻辑。

## 验收标准

- 桌面宽屏下，助手气泡左边缘与输入框左边缘对齐。
- 桌面宽屏下，用户气泡右边缘与输入框右边缘对齐。
- 长用户消息不会超出内容轨道。
- 窄屏下消息与输入框保持一致边距。
- React lint、TypeScript 编译和 Vite 构建通过。
