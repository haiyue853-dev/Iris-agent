# MCP 服务环境变量实现计划

目标：让每个本地 stdio MCP 服务可配置环境变量，同时避免通过列表与日志泄露变量值。

1. 在 `McpServer` 持久化 `env` 映射；校验变量名、数量和值长度，并在更新时关闭当前持久会话。
2. 子进程环境由系统环境与服务环境合并；服务环境优先，仅传给该 MCP 子进程。
3. API 新增独立更新端点；所有服务序列化结果只公开 `env_keys`，不公开值。
4. MCP 页面在服务卡片提供“环境变量”编辑区，支持每行 `KEY=VALUE` 保存，并只在重新进入页面后显示名称。
5. 以服务/API/页面测试覆盖持久化、脱敏、更新关闭会话和编辑请求；随后运行全量后端、前端与构建验证。
